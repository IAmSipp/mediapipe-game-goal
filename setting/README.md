# ตั้งค่าเกมผู้รักษาประตู
แก้ไฟล์แล้วบันทึก ปิดและเปิดเกมใหม่

- `game_settings.py`: เวลา คะแนน ขนาดบอล/ถุงมือ สกิล และสี
- `control_settings.py`: เลือกสำเร็จรูปและปรับ MediaPipe
- `hand_controls.py`: เขียนกฎตำแหน่งถุงมือและท่ากดสกิลเอง
- `__init__.py`: ไม่ต้องแก้

## เริ่มจากสำเร็จรูป
ตั้ง `USE_PRESET = True` ใน control_settings.py
เลื่อนมือทั้งสองข้างเพื่อขยับวงถุงมือ
กำมือเพื่อใช้สกิล คลายมือก่อนกดใหม่
เลือก SKILL_ACTION เป็นกำมือข้างใดก็ได้/ซ้าย/ขวา/สองข้าง

## ตัวอย่างปรับง่าย
```python
USE_PRESET = True
HOLD_SECONDS = 0.25
MIN_DETECTION_CONFIDENCE = 0.6
```
ต้องกำค้าง 0.25 วินาที และเพิ่มเกณฑ์ตรวจมือเป็น 0.6
ปรับ MOVEMENT_GAIN เพื่อให้ขยับมือน้อยหรือมากขึ้น
ตั้ง `USE_PRESET = False` เพื่อใช้ hand_controls.py เท่านั้น
กฎเขียนเองคืน `{"gloves": {"Left": (x, y)}, "skill": False}` พิกัด 0–1
