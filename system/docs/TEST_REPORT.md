# ผลตรวจเกมผู้รักษาประตู

วันที่ 19 พฤศจิกายน 2026 ทดสอบบน Windows / Python 3.13.1
ใช้ environment ใหม่ของโปรเจกต์และ requirements.txt ตามต้นแบบ

| ประเภท | ผล |
|---|---|
| จำลอง | ผ่าน 26 tests: เริ่ม/จบ/เล่นใหม่, เวลาและคะแนน, ถุงมือทั้งสองข้าง, การหายของมือ, ท่ากำมือ, dwell, คูลดาวน์, สกิลทั้งสาม, การแยก preset/custom และคืน resource |
| ลูปเกมจำลอง | เรียก main จริงด้วยกล้อง เวลา และ mouse events จำลอง ครบ MENU → PLAYING → GAME_OVER → PLAYING ทั้ง True/False |
| ภาพหน้าจอจำลอง | สร้าง 14 ภาพ ครบเมนู เล่น จบ กล้องผิดพลาด และสกิลทั้งสาม ในสองโหมด ตรวจภาพเมนูและเล่นด้วยสายตาแล้ว |
| โมเดลจริงกับภาพนิ่ง | ผ่านภาพมือ 3 แบบและภาพกลับซ้ายขวา รวม 6 กรณี ตรวจ handedness ตำแหน่งถุงมือและคำสั่งกำมือทั้งสองโหมด |
| กล้องจริง | นอก sandbox เปิดกล้อง 0 และอ่านได้โหมดละ 24 เฟรม รวม 48 เฟรม ไม่มี error ปิดและเปิดใหม่ได้ |
| ท่าจากผู้เล่นจริง | ยังไม่ได้ทดสอบ: ไม่มีมือในเฟรมกล้องจริง จึงยังไม่ยืนยันการขยับแขน กำมือ คูลดาวน์ หรือเล่นครบหนึ่งรอบกับคนจริง |

การเปิดกล้องใน sandbox ครั้งแรกไม่สำเร็จ เมื่อทดสอบนอก sandbox เปิดได้
ไม่ได้บันทึกภาพถ่ายจากกล้องจริง ผลอ่านกล้องและจำนวนเฟรมอยู่ใน system/artifacts/manual-checks.json
ภาพนิ่งที่ใช้มาจากโฟลเดอร์ผลทดสอบ local ของต้นแบบ ไม่ได้คัดลอก artifacts เก่าเข้าโปรเจกต์ใหม่
ภาพ UI ใน artifacts เป็นข้อมูลจำลองทั้งหมด

ตรวจข้อกำหนดแล้ว: setting สองไฟล์เป็น literal data; system ไม่มี Python comments/docstrings;
ไฟล์สำหรับ AI, PROJECT_FORMAT.md, .venv, caches, artifacts และ ZIP ถูก ignore
ไม่ได้อัปโหลด GitHub และไม่ได้สร้าง ZIP แจกผู้เรียน

รันทดสอบซ้ำ:
```powershell
.\.venv\Scripts\python.exe -m unittest discover -s system/tests -v
```

ดูขั้นตอนลองเล่นกับคนจริงใน CONTROL_DETAILS.md

## ตรวจซ้ำหลังปรับฉากสนามฟุตบอล

ทดสอบจำลองเดิมผ่านทั้ง 26 tests และวาดภาพหน้าจอใหม่ครบ 14 ภาพ
ตรวจภาพขณะเล่นและโล่ประตูด้วยสายตาแล้ว: สนาม เส้นเขตโทษ ผู้ยิง อัฒจันทร์ เสาและคานแสดงผลครบ
รอบนี้เปลี่ยนเฉพาะภาพและสี ไม่ได้ลองกล้องจริงซ้ำ
